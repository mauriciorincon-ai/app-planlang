¿Y si el plan hubiera fijado otros umbrales?What if the plan had set other thresholds?

Mueve los umbrales del plan y mira qué casos habrían tomado otro camino, qué errores aparecen o se evitan y cuánto trabajo humano cuesta. Todo se recalcula sobre las decisiones que el agente ya tomó: nadie vuelve a llamar al modelo.Move the plan’s thresholds and see which cases would have taken another path, which errors appear or are avoided and how much human work it costs. Everything is recalculated over the decisions the agent already made: nobody calls the model again.

Las decisiones humanas de esta corrida se simularon.This run’s human decisions were simulated. En cada pausa, un auditor simulado respondió lo que dice la verdad conocida del caso (DA-04). Lo que el playground no puede saberWhat the playground cannot know

  • Mover un umbral recalcula, sobre las señales registradas, qué rama habría tomado cada nodo que decide. Lo que el agente habría hecho después (otra extracción, otra respuesta) no se simula: se marca «no observado».Moving a threshold recomputes, on the recorded signals, which branch each deciding node would have taken. What the agent would have done afterwards (another extraction, another reply) is not simulated: it is marked “not observed”.
  • U4 (Modo Texas): conmutarlo cambia 0 de las 62 decisiones registradas en esta corrida.U4 (Texas mode): switching it changes 0 of the 62 decisions recorded in this run.
  • La regla texas_y_no_aprobar(modo_texas, propuesta) se puede recalcular: sus entradas están en todas las trazas.The texas_y_no_aprobar(modo_texas, propuesta) rule can be recomputed: its inputs are in every trace.
En esta maqueta, el cálculo lo hace un guion de sala sobre las señales reales.In this mock-up, a room script does the calculation over the real signals. En el producto lo hace el núcleo de planlang, el mismo intérprete que ya coincide con Python en las 233 decisiones de la corrida.In the product, planlang’s core does it: the same interpreter that already matches Python on the run’s 233 decisions.
