# diagramador (copia fijada del contrato)

Reusable de la casa planeadora. En el S1 de planlang solo existe `CONTRATO.lock` (versión 0.2.0 y huella
SHA-256 del contrato). La implementación (mapa bajo la gramática `agentes-ia`, conversor desde el grafo
compilado, SVG cuando exista el piloto) llega en el S2 con el visor. Este paquete no importa nada de la app.
