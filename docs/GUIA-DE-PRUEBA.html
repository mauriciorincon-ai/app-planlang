Guía de prueba

Todas las pruebas vigentes de la app, con su origen. En el sprint 1 no hay pantalla: se prueba en la terminal y leyendo archivos del repo. Las casillas se guardan solas en este navegador.

Gate corto ⭐⭐: 3 paradas · ~15 min — obligatorio en este sprint, no se difiere. Solo lo que únicamente tú puedes juzgar: correr el lote con tu suscripción, leer el informe y mirar el espejo en LangSmith. Deja fuera 2 pruebas ⭐ (bloque D) porque la CI ya las verifica; ninguna se borra.

Gate mínimo ⭐: 5 pruebas · ~20 min. Las 3 paradas más la re-verificación de confianza del bloque D. Todo lo demás lo verifica la CI (golden files, prueba cruzada de ramas, M9, validador de identificadores): bloques E–H, y el kit de prueba en docs/kit-de-prueba/.

Dónde se prueba

Una terminal abierta en la raíz del repositorio (~/Code/app-planlang), con pnpm install hecho y Claude Code con tu sesión iniciada. Sin URL: el S1 no tiene pantalla.

Cada bloque abre con «Empieza en:»: la terminal, un archivo del repo o un servicio. Ve ahí antes de empezar el bloque.
